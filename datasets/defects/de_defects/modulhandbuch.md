# INF301 Algorithmen — Modulhandbuch

Dieses Modul behandelt Entwurf und Analyse von Algorithmen. Prüfung: Klausur (100%).

## Lernziele
Die Studierenden können die binäre Suche in einem sortierten Array erklären.
Die Studierenden können Verkettung und offene Adressierung bei Kollisionen in Hashtabellen vergleichen.
Die Studierenden können die Tiefensuche auf einen Graphen anwenden.
Die Studierenden können Lösungen mit dynamischer Programmierung für das Rucksackproblem entwerfen.

## Zeitplan
Woche 1: Binäre Suche
Woche 2: Hashtabellen
Woche 3: Graphen und Tiefensuche
Woche 4: Dynamische Programmierung
