Sorting algorithms. Insertion sort and merge sort order a list of numbers. Insertion sort needs quadratic time in the worst case; merge sort halves the list, sorts both halves and merges the sorted halves in n log n time.

Binary search. Binary search halves the search space of a sorted array in every step. Its running time is logarithmic in the array length, so 1024 entries need at most 10 comparisons.

Hash tables. A hash function maps keys to table slots. Collisions occur when two keys share a slot; chaining stores colliding entries in a linked list, open addressing probes for the next free slot. The load factor controls the expected lookup cost.
