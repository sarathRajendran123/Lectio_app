# CS300 Algorithms Basics — Module Manual

This module introduces three fundamental algorithm topics. Assessment: written exam (100%).

## Learning outcomes
Students will be able to:
- explain how insertion sort and merge sort order a list of numbers
- analyse the running time of binary search on a sorted array
- evaluate chaining and open addressing for collisions in hash tables

## Weekly schedule
Week 1: Sorting algorithms
Week 2: Binary search
Week 3: Hash tables
