# CS301 Algorithms — Module Manual

This module covers the design and analysis of algorithms. Assessment: written exam (100%).

## Learning outcomes
Students will be able to:
- explain how insertion sort and merge sort order a list of numbers
- analyse the running time of binary search on a sorted array
- evaluate chaining and open addressing for collisions in hash tables
- apply breadth-first search to traverse a graph
- design dynamic programming solutions for optimisation problems such as the knapsack problem

## Weekly schedule
Week 1: Sorting algorithms
Week 2: Binary search
Week 3: Hash tables
Week 4: Graph traversal
Week 5: Dynamic programming
